# ListItemAvatar

Profile avatar for list item.

## Example

```tsx
import { ListItemAvatar } from "@miyauci/material-react";

<ListItemAvatar>A</ListItemAvatar>;
```

## Props

| Name       | Type        |
| ---------- | ----------- |
| `children` | `ReactNode` |

And `HTMLSpanElement` arrtibutes.
