# ListItemText

Supporting text for list item.

## Example

```tsx
import { ListItemText } from "@miyauci/material-react";

<ListItemText>100+</ListItemText>;
```

## Props

| Name       | Type        |
| ---------- | ----------- |
| `children` | `ReactNode` |

And `HTMLSpanElement` arrtibutes.
