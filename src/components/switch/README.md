# Switch

Switches toggle the selection of an item on or off.

## Example

```tsx
import { Switch } from "@miyauci/material-react";

<Switch />;
```

## Props

| Name       | Type         |
| ---------- | ------------ |
| `selected` | `boolean`    |
| `state`    | `"disabled"` |
| `icon`     | `ReactNode`  |

And `HTMLButtonElement` arrtibutes.
